# Data-Engineering-RoadMap

## Overview.

Welcome to Data Engineering Course. This repository documents my progress as I work towards becoming a Data Engineer, from programming in Python and databases to developing data pipelines, working with cloud technologies, and designing scalable data solutions.

In this course you'll develop the skills required to work as a Data Engineer.

* Python and SQL
* Data modelling and databases
* ETL and ELT pipelines
* Data warehousing
* Cloud technologies: Microsoft Certified: Azure Data Fundamentals(DP-900)
* Distributed data processing
* Data orchestration
* Infrastructure and deployment
* Data quality and testing
* Software engineering best practices
* Data Visualisation: Microsoft Certified: Power BI Data Analyst Associate(PL-300)
